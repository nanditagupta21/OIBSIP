# Oasis Infobyte Internship – Web Development & Designing (Level 1)

## About the Internship

This repository contains my Level 1 projects completed as part of the **Oasis Infobyte Web Development & Designing Internship (OIBSIP)**.

The projects helped me strengthen my understanding of frontend development, responsive web design, HTML, CSS, and JavaScript.

## Level 1 Tasks

### Task 1: Landing Page – ExploreWorld

**Description:**  
Designed and developed a responsive travel website landing page named ExploreWorld.

**Features:**
- Navigation bar with different sections.
- Attractive hero section.
- About ExploreWorld section.
- Why Choose Us section.
- Contact section.
- Footer with copyright information.
- Responsive layout for different screen sizes.

**Technologies Used:** HTML5, CSS3.

**Project Folder:** `WebDev-L1-LandingPage`

### Task 2: Personal Portfolio Website

**Description:**  
Created a personal portfolio website to introduce myself, showcase my technical skills, and display my projects.

**Features:**
- Home section with personal introduction.
- About Me section.
- Technical Skills section.
- Projects showcase.
- Contact section.
- Responsive design.
- Links to view projects and contact me.

**Technologies Used:** React.js, Vite, HTML, CSS, JavaScript.

**Live Website:** https://my-portfolio-ten-nu-17.vercel.app/

**Project Folder:** `WebDev-L1-PersonalPortfolio`

### Task 3: Temperature Converter

**Description:**  
Developed an interactive temperature converter that converts temperature values between Celsius, Fahrenheit, and Kelvin.

**Features:**
- Celsius to Fahrenheit and Kelvin conversion.
- Fahrenheit to Celsius and Kelvin conversion.
- Kelvin to Celsius and Fahrenheit conversion.
- Input validation.
- Error handling for invalid temperature values.
- Responsive user interface.
- Modern dark-themed design with gradient effects.

**Technologies Used:** HTML5, CSS3, JavaScript.

**Project Folder:** `WebDev-L1-TemperatureConverter`
